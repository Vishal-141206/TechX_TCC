# 🎬 Demo Video Script - Privacy-First Personal Finance Manager

## 📋 Video Overview

**Duration:** 3-4 minutes  
**Target Audience:** Investors, hackathon judges, potential users  
**Goal:** Showcase the app's unique privacy-first approach and powerful AI features  
**Tone:** Professional, confident, privacy-focused

---

## 🎯 Key Messages to Convey

1. **100% Privacy** - All processing happens on-device, no cloud required
2. **Smart AI** - Extracts financial insights from SMS automatically
3. **Predictive** - Forecasts next month's finances
4. **Protective** - Detects scam/phishing messages
5. **Accessible** - Voice interface for hands-free use

## 🎨 VISUAL STYLE GUIDE

### Color Scheme

- **Primary:** Material 3 theme colors
- **Accent:** Green for surplus, Red for deficit
- **Background:** Clean white/light theme
- **Text Overlays:** Dark text on light semi-transparent backgrounds

### Typography

- **Title Cards:** Bold, large sans-serif (Montserrat, Inter)
- **Body Text:** Clean, readable (Roboto, Open Sans)
- **Code/JSON:** Monospace font (JetBrains Mono, Fira Code)

### Transitions

- **Between Scenes:** 0.5s smooth fade
- **Within App:** Show actual app transitions (no cuts)
- **Text Overlays:** Fade in 0.3s, hold 2s, fade out 0.3s

### Music (Background)

- **Style:** Minimal, modern, tech-inspired
- **Volume:** Low (25-30% max), don't overpower narration
- **Recommendations:**
    - Upbeat but professional
    - No lyrics
    - Consistent energy throughout
    - Royalty-free (YouTube Audio Library, Epidemic Sound)

### Graphics Overlays

- **Icons:** Use Material Design icons
- **Arrows/Highlights:** Circle important UI elements
- **Stats:** Animated counters for numbers
- **Privacy Badge:** "100% Local" badge always visible corner

## 📊 DEMO DATA PREPARATION

### Sample SMS Messages to Parse (Indian Banking Format)

1. **Credit/Salary:**
   ```
   Dear Customer, your A/c XX1234 is credited with Rs. 45,000.00 on 01-Jan-25. 
   Ref: SALARY/JAN25. Available Bal: Rs. 52,340.50 -HDFC Bank
   ```

2. **Debit/Subscription:**
   ```
   Rs. 199.00 debited from A/c XX1234 for Netflix on 05-Jan-25. 
   Available Bal: Rs. 48,141.50 -HDFC Bank
   ```

3. **Debit/Shopping:**
   ```
   Your A/c XX1234 debited for Rs. 1,250.00 at Amazon India on 08-Jan-25. 
   Avl Bal: Rs. 46,891.50 -HDFC Bank
   ```

4. **Debit/Food:**
   ```
   Rs. 485.00 debited from A/c XX1234 for Swiggy on 10-Jan-25. 
   UPI: swiggy@upi. Bal: Rs. 46,406.50 -HDFC Bank
   ```

5. **Scam/Phishing Example:**
   ```
   URGENT: Your bank account will be blocked! Click here immediately: 
   http://fakebank-verify.com/update and enter your OTP to reactivate.
   ```

### Expected Prediction Output

Based on 15-20 parsed messages, the prediction should show:

- **Expected Income:** ₹45,000 (from salary SMS)
- **Expected Expenses:** ₹8,000-10,000 (from various debits)
- **Net Cash Flow:** +₹35,000-37,000 (surplus)
- **Confidence:** Medium (15-20 transactions)

**Key Insights Should Include:**

- "Your savings rate is 78.2% - excellent!"
- "You have 2-3 active subscriptions"
- "Food spending: ₹2,500-3,000/month"
- "Entertainment: ₹500-800/month"
